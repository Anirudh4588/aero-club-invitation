# Aero Club Vignan - Oath Taking Ceremony Invitation ✈️

An interactive, responsive digital invitation experience for the **Vignan Aero Club Oath Taking Ceremony**, featuring blue stage curtain reveal animations, smooth 3D page flip transitions, Bodoni Moda typography, custom aeronautical corner accents, an animated sky aircraft fleet, and venue location.

![License](https://img.shields.io/badge/License-MIT-gold?style=for-the-badge)

---

## 🌟 Features

- **🎭 Blue Silk Stage Curtains**: Grand opening reveal with realistic 3D pleats, gold tassels, and synthesized harmonic audio chime.
- **🛫 3D Card Pop-Up**: Slower, majestic rise into view with realistic 3D depth and soft drop-shadows.
- **⏱️ 7.0-Second Continuous Auto-Timer**: Circular SVG countdown progress ring that automatically flips between pages.
- **✨ 2-Page Flow**:
  - **Page 1 (Boarding Pass)**: Aero Club crest, skydiver illustration, date (`17th September`), time (`10:40 am to 12:20 pm`), and perforated boarding stub.
  - **Page 2 (Venue & Location)**: Detailed address for *Vignan Institute of Technology & Science*, interactive Google Maps embed, directions link, and 1-click **Add to Calendar (.ics)**.
- **✈️ Sky Aircraft Fleet**: Supersonic fighter jet, commercial airliner, propeller plane, paper airplanes, and drone soaring across the background sky with realistic contrails and forward-facing flight physics.
- **📱 Universal Compatibility**:
  - **Mobile**: Touch swiping left/right on iOS Safari & Android Chrome.
  - **Laptops / Desktops**: Mouse drag and keyboard arrow keys (`←` / `→` / `Space`).

## 🚀 Quick Start

### Run locally:

You can open `index.html` directly in any web browser, or serve it with Python / Node:

```bash
# Using Python
python -m http.server 4000

# Using Node.js npx
npx serve -l 4000
```

Then visit: `http://localhost:4000`
